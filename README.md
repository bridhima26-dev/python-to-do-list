# Python To-Do List
A terminal-based To-Do List application built with Python using file handling for persistent task storage.

## Features

- View tasks
- Add tasks
- Remove tasks
- Clear all tasks
- Tasks remain saved after closing the program

## Concepts Practiced

- File handling
- Lists
- Loops
- Conditional statements
- String manipulation
- Match-case statements

## Project Structure

```text
todolist.py
todo.txt
```

## How to Run

1. Make sure Python is installed.
2. Create an empty file named `todo.txt` in the project directory.
3. Run:

```bash
python todolist.py
```

## Current Limitations

- Task data is stored in a plain text file.
- Input validation is limited and non-numeric menu inputs may cause errors.
- Tasks do not support priorities or due dates.
- The application runs only in the terminal.
- Task numbering is managed manually within the file.

## Future Improvements

- Better input validation using `try-except`
- Search for tasks
- Task priorities
- Due dates
- Graphical user interface (GUI)

## About

This project was created while learning Python and practicing file handling through a real-world terminal application.
